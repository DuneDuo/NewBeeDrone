# MAVLink 消息字段参考 — Handler 开发手册

> 来源：`common.xml`（PX4 / ArduPilot 共用，pymavlink v2.0 协议定义）
> 当前飞控：PX4（autopilot=12）
> 用途：写 `handlers.py` 时查每个消息有哪些字段、什么单位、怎么换算
> **只列服务器需要处理的消息。每个字段标注了 Python 访问名、原始单位、建议换算。**

---

## 约定

- **Python 访问**：`msg.字段名` 直接读，pymavlink 自动把 XML 的 snake_case 转成 Python 属性
- **单位**：XML 原始单位 → **建议的 Python 换算**
- **互斥说明**：同名参数出现在多个消息中时，标注来源和区别

## 2. SYS_STATUS（id=1） — 系统状态

| Python 字段 | 原始单位 | 换算 | 说明 |
|-------------|---------|------|------|
| `onboard_control_sensors_present` | 位掩码 | 直接读 | 哪些传感器存在 |
| `onboard_control_sensors_enabled` | 位掩码 | 直接读 | 哪些传感器启用 |
| `onboard_control_sensors_health` | 位掩码 | 直接读 | 哪些传感器健康（0=故障, 1=正常） |
| `load` | d%（1/10 %） | `msg.load / 10` | CPU 负载百分比，最大 1000（即100%） |
| `voltage_battery` | mV | `msg.voltage_battery / 1000` | 电池电压（V）。UINT16_MAX=未发送 |
| `current_battery` | cA（10mA） | `msg.current_battery / 100` | 电池电流（A）。-1=未发送 |
| `battery_remaining` | % | 直接读 | 剩余电量百分比。-1=未发送 |
| `drop_rate_comm` | c%（1/100 %） | `msg.drop_rate_comm / 100` | 通信丢包率（%） |
| `errors_comm` | — | 直接读 | 通信错误计数 |
| `errors_count1` ~ `count4` | — | 直接读 | 飞控内部错误计数 |

> **注意**：ArduPilot 现在推荐用 `BATTERY_STATUS`（id=147）取电池数据，字段更全。
> `SYS_STATUS` 的 `battery_remaining` 和 `BATTERY_STATUS` 的 `battery_remaining` 是同名同含义，
> 但 `BATTERY_STATUS` 额外提供了 `temperature`、`current_consumed`、`time_remaining` 等。

## 4. GPS_RAW_INT（id=24） — GPS 原始数据

| Python 字段 | 原始单位 | 换算 | 说明 |
|-------------|---------|------|------|
| `time_usec` | μs | `msg.time_usec / 1e6` | 时间戳 |
| `fix_type` | — | 直接读 | GPS 定位类型（2=2D, 3=3D, 4=RTK浮点, 5=RTK固定） |
| `lat` | degE7（度×1e7） | `msg.lat / 1e7` | 纬度 |
| `lon` | degE7（度×1e7） | `msg.lon / 1e7` | 经度 |
| `alt` | mm | `msg.alt / 1000` | 海拔高度 MSL（米） |
| `eph` | 无（×1e-2） | `msg.eph * 1e-2` | 水平精度因子 HDOP |
| `epv` | 无（×1e-2） | `msg.epv * 1e-2` | 垂直精度因子 VDOP |
| `vel` | cm/s | `msg.vel / 100` | 地面速度（m/s） |
| `cog` | cdeg（度×100） | `msg.cog / 100` | 地面航向（度），注意这是运动方向不是机头朝向 |
| `satellites_visible` | — | 直接读 | 可见卫星数 |
| `alt_ellipsoid` | mm | `msg.alt_ellipsoid / 1000` | 椭球高度（WGS84 椭球，米），非 MSL |
| `h_acc` | mm | `msg.h_acc / 1000` | 水平位置精度估计（米） |
| `v_acc` | mm | `msg.v_acc / 1000` | 垂直位置精度估计（米） |
| `vel_acc` | mm/s | `msg.vel_acc / 1000` | 速度精度估计（m/s） |
| `hdg_acc` | degE5（度×1e5） | `msg.hdg_acc / 1e5` | 航向精度估计（度） |
| `yaw` | cdeg（度×100） | `msg.yaw / 100` | GPS 提供的偏航角（度），0=不支持 |

> **与 GLOBAL_POSITION_INT（id=33）的区别**：GPS_RAW_INT 是 GPS 传感器**原始值**，
> GLOBAL_POSITION_INT 是经过 EKF 融合后的**估计值**。日常导航用 GLOBAL_POSITION_INT，
> 需要知道 GPS 信号质量（卫星数、fix_type、精度因子）时才用 GPS_RAW_INT。

## 6. GLOBAL_POSITION_INT（id=33） — 全局位置（融合估计值）

| Python 字段 | 原始单位 | 换算 | 说明 |
|-------------|---------|------|------|
| `time_boot_ms` | ms | `msg.time_boot_ms / 1000` | 上电后时间（秒） |
| `lat` | degE7（度×1e7） | `msg.lat / 1e7` | 纬度 |
| `lon` | degE7（度×1e7） | `msg.lon / 1e7` | 经度 |
| `alt` | mm | `msg.alt / 1000` | 海拔高度 MSL（米） |
| `relative_alt` | mm | `msg.relative_alt / 1000` | 相对起飞点高度（米） |
| `vx` | cm/s | `msg.vx / 100` | 地面 X 速度（m/s），北为正 |
| `vy` | cm/s | `msg.vy / 100` | 地面 Y 速度（m/s），东为正 |
| `vz` | cm/s | `msg.vz / 100` | 地面 Z 速度（m/s），下为正 |
| `hdg` | cdeg（度×100） | `msg.hdg / 100` | 航向角（度），0=北，范围 0~360 |

> **与 GLOBAL_POSITION_INT_COV（id=63）的区别**：id=63 多了 6×6 协方差矩阵和 `estimator_type`，
> 带宽占用大。日常用 id=33 就够了。

> **`relative_alt`（此消息里的） vs `altitude_relative`（ALTITUDE 消息里的）**：
> 两个都是相对起飞点高度，但来源不同。`relative_alt` 来自 GLOBAL_POSITION_INT（单位 mm），
> `altitude_relative` 来自 ALTITUDE（单位 m）。选用任意一个即可，不要混用。

## 8. MISSION_CURRENT（id=42） — 当前任务航点

| Python 字段 | 原始单位 | 换算 | 说明 |
|-------------|---------|------|------|
| `seq` | — | 直接读 | 当前正在飞向的航点序号 |
| `total` | — | 直接读 | 航点总数。UINT16_MAX=无任务 |
| `mission_state` | — | 直接读 | 任务状态机状态，取值见下表 |
| `mission_mode` | — | 直接读 | 是否任务模式（0=未知, 1=任务中, 2=暂停） |

**`mission_state` 取值**（`MAV_MISSION_STATE` 枚举，共 6 种）：

| 值 | 名称 | 含义 |
|:--:|------|------|
| 0 | `MAV_MISSION_STATE_UNKNOWN` | 不支持任务状态上报 / 未知 |
| 1 | `MAV_MISSION_STATE_NO_MISSION` | 机上没有任务 |
| 2 | `MAV_MISSION_STATE_NOT_STARTED` | 任务已上传但还没开始执行 |
| 3 | `MAV_MISSION_STATE_ACTIVE` | 任务激活，auto 模式下会执行航点 |
| 4 | `MAV_MISSION_STATE_PAUSED` | 任务暂停（auto 模式下） |
| 5 | `MAV_MISSION_STATE_COMPLETE` | 任务已执行完所有航点 |

## 9. MISSION_ITEM_REACHED（id=46） — 航点到达

| Python 字段 | 原始单位 | 换算 | 说明 |
|-------------|---------|------|------|
| `seq` | — | 直接读 | 刚刚到达的航点序号 |

> **与 MISSION_CURRENT（id=42）的区别**：`MISSION_CURRENT` 是"正在飞向哪个航点"（出发时发），
> `MISSION_ITEM_REACHED` 是"已经到达哪个航点"（到达时发）。**触发业务动作（如投放）用这个。**
> 只有 `seq` 一个有效字段，没有 total/mission_state 等。

## Mission 协议（上传/下载任务）

> 服务器是"调度大脑"：**规划好整条路线，一次性上传给飞控，飞控自主执行**，服务器只监控。
> 上传**不是 `command_long`**，而是专门的 `MISSION_*` 消息，是一个"飞控请求一条、服务器发一条"的握手协议。

### 上传握手流程

```
服务器 → 飞控: MISSION_COUNT(count=N)         "要传 N 条"
飞控 → 服务器: MISSION_REQUEST_INT(seq=0)     "把第 0 条发我"
服务器 → 飞控: MISSION_ITEM_INT(seq=0)        "第 0 条：起飞"
飞控 → 服务器: MISSION_REQUEST_INT(seq=1)     "把第 1 条发我"
服务器 → 飞控: MISSION_ITEM_INT(seq=1)        "第 1 条：飞投放点"
            …逐条…
飞控 → 服务器: MISSION_ACK(type=0)            "全部收到，上传成功"
```

启动执行：发 `MAV_CMD_MISSION_START`(300)（command_long）或切 AUTO 模式。

### 消息字段

**接收（写 handler）**：

**`MISSION_REQUEST_INT`（id=51）— 飞控请求下一条**

| Python 字段 | 换算 | 说明 |
|-------------|------|------|
| `seq` | 直接读 | 请求第几个 item |
| `mission_type` | 直接读 | 任务类型（MAV_MISSION_TYPE，见下） |

**`MISSION_ACK`（id=47）— 飞控确认上传结果**

| Python 字段 | 换算 | 说明 |
|-------------|------|------|
| `type` | 直接读 | 结果（MAV_MISSION_RESULT，见下） |
| `mission_type` | 直接读 | 任务类型 |

**发送（drone.py 方法，不写 handler）**：

**`MISSION_COUNT`（id=44）— 声明要传几条**

| Python 字段 | 说明 |
|-------------|------|
| `count` | item 总数 |
| `mission_type` | 任务类型 |

**`MISSION_ITEM_INT`（id=73）— 一个航点/动作**（服务器发给飞控的核心）

| Python 字段 | 说明 |
|-------------|------|
| `seq` | 序号（0 开始） |
| `frame` | 坐标系（MAV_FRAME，见下） |
| `command` | 指令（MAV_CMD，决定这是航点还是动作） |
| `current` | 是否当前项（填 0） |
| `autocontinue` | 是否自动继续下一个（填 1） |
| `param1` ~ `param4` | 指令参数（含义取决于 command） |
| `x` `y` `z` | 位置（int32，degE7 或 mm，取决于 frame） |
| `mission_type` | 任务类型 |

**`MISSION_REQUEST_LIST`（id=43）**：请求下载飞控上的任务（校验用）
**`MISSION_CLEAR_ALL`（id=45）**：清空飞控任务
**`MISSION_SET_CURRENT`（id=41）**：设置当前航点序号 `seq`

### 关键枚举

**`MAV_CMD`（MISSION_ITEM_INT.command，投递场景常用）**

| 值 | 名称 | 用途 |
|:--:|------|------|
| 16 | `NAV_WAYPOINT` | 飞往航点 |
| 22 | `NAV_TAKEOFF` | 起飞 |
| 21 | `NAV_LAND` | 降落 |
| 20 | `NAV_RETURN_TO_LAUNCH` | 返航 |
| 19 | `NAV_LOITER_TIME` | 悬停 N 秒（投放点上空悬停） |
| 183 | `DO_SET_SERVO` | 开舱投放（舵机） |
| 211 | `DO_GRIPPER` | 投放（机械爪） |
| 178 | `DO_CHANGE_SPEED` | 改变飞行速度（投放前减速） |
| 300 | `MISSION_START` | 启动任务（command_long） |
| 400 | `COMPONENT_ARM_DISARM` | 解锁/上锁 |

**`MAV_FRAME`（MISSION_ITEM_INT.frame）**

| 值 | 名称 | 说明 |
|:--:|------|------|
| 3 | `GLOBAL_RELATIVE_ALT` | 全局坐标 + **相对起飞点高度**（推荐） |
| 0 | `GLOBAL` | 全局坐标 + 绝对高度 MSL |
| 1 | `LOCAL_NED` | 本地 NED 坐标 |

**`MAV_MISSION_RESULT`（MISSION_ACK.type）**

| 值 | 名称 | 含义 |
|:--:|------|------|
| 0 | `ACCEPTED` | ✅ 上传成功 |
| 1 | `ERROR` | 错误 |
| 2 | `UNSUPPORTED_FRAME` | 坐标系不支持 |
| 3 | `UNSUPPORTED` | 不支持 |
| 4 | `NO_SPACE` | 存储空间不足 |
| 5 | `INVALID` | 无效 |
| 6 / 7 | `INVALID_PARAM1` / `INVALID_PARAM2` | 第 1/2 个参数无效 |

**`MAV_MISSION_TYPE`（mission_type 字段）**

| 值 | 名称 | 说明 |
|:--:|------|------|
| 0 | `MISSION` | 任务（用这个） |
| 1 | `FENCE` | 电子围栏 |
| 2 | `RALLY` | 集结点 |
| 255 | `ALL` | 全部 |

### drone.py 要加的方法

| 方法 | 发的消息 | 用途 |
|------|---------|------|
| `mission_count(n)` | `MISSION_COUNT` | 声明传 N 条 |
| `mission_item_int(seq, cmd, x, y, z, ...)` | `MISSION_ITEM_INT` | 发一条航点/动作 |
| `mission_request_list()` | `MISSION_REQUEST_LIST` | 请求下载任务 |
| `mission_clear_all()` | `MISSION_CLEAR_ALL` | 清空任务 |
| `mission_set_current(seq)` | `MISSION_SET_CURRENT` | 设置当前航点 |
| `mission_start()` | `command_long(300)` | 启动任务（这个是 command_long） |

## 13. COMMAND_ACK（id=77） — 指令确认

| Python 字段 | 原始单位 | 换算 | 说明 |
|-------------|---------|------|------|
| `command` | — | 直接读 | 被确认的指令 ID（对应 MAV_CMD 枚举） |
| `result` | — | 直接读 | 执行结果 |
| `progress` | % | 直接读 | 进度（仅 result=IN_PROGRESS 时有效） |
| `result_param2` | — | 直接读 | 附加结果信息 |
| `target_system` | — | 直接读 | 原指令发送方的 sys_id |
| `target_component` | — | 直接读 | 原指令发送方的 com_id |

**`result` 取值**：

| 值 | 含义 |
|:--:|------|
| 0 | MAV_RESULT_ACCEPTED — 成功执行 |
| 1 | MAV_RESULT_TEMPORARILY_REJECTED — 暂时拒绝 |
| 2 | MAV_RESULT_DENIED — 拒绝 |
| 3 | MAV_RESULT_UNSUPPORTED — 不支持 |
| 4 | MAV_RESULT_FAILED — 执行失败 |
| 5 | MAV_RESULT_IN_PROGRESS — 执行中（长指令先回这个，**不是最终结果**） |
| 7 | MAV_RESULT_COMMAND_LONG_ONLY — 该指令仅接受 command_long 形式 |
| 8 | MAV_RESULT_COMMAND_INT_ONLY — 该指令仅接受 command_int 形式 |

> 注：`6=MAV_RESULT_CANCELLED`、`9=MAV_RESULT_COMMAND_UNSUPPORTED_MAV_FRAME` 在标准 MAVLink 里存在，
> 但当前 pymavlink 2.4.49 的 common 模块未定义这两个常量（飞控固件仍可能发送，`result` 字段本身是 uint8 直接读，不影响解析）。

| `altitude_amsl` | m | 直接读 | 海拔高度 MSL（米） |
| `altitude_local` | m | 直接读 | 本地坐标系高度（相对坐标原点） |
| `altitude_relative` | m | 直接读 | 相对起飞点高度（米） |
| `altitude_terrain` | m | 直接读 | 相对地形高度（米），需测距仪/地形数据库。<-1000=未知 |
| `bottom_clearance` | m | 直接读 | 底部净空（米），激光测距仪的可用距离 |

> 但 ALTITUDE 里单位是 **m**（直接读），GLOBAL_POSITION_INT 里单位是 **mm**（须 `/1000`）。

## 同名字段汇总（写 handler 时注意）

| 字段名 | 出现在哪些消息 | 区别 |
|--------|--------------|------|
| `lat` | GLOBAL_POSITION_INT(33)、GPS_RAW_INT(24) | 都是纬度×1e7，换算相同 |
| `lon` | GLOBAL_POSITION_INT(33)、GPS_RAW_INT(24) | 相同 |
| `alt` | GLOBAL_POSITION_INT(33, mm→m)、GPS_RAW_INT(24, mm→m)、VFR_HUD(74, m) | 单位不同！33/24 需 `/1000`，74 直接读 |

| `roll` / `pitch` / `yaw` | ATTITUDE(30, rad)、MANUAL_SETPOINT(81, rad/s 目标角速度) | ATTITUDE 是当前姿态，81 是控制指令不要混 |

## 附录 A：位掩码详解

### A.1 `base_mode`（HEARTBEAT）— MAV_MODE_FLAG

> 来源：`minimal.xml`

| 位值 | 标识符 | 含义 |
|:----:|--------|------|
| **128** | `MAV_MODE_FLAG_SAFETY_ARMED` | 已解锁，电机可转 / 正在转 |
| 64 | `MAV_MODE_FLAG_MANUAL_INPUT_ENABLED` | 遥控器输入已启用 |
| 32 | `MAV_MODE_FLAG_HIL_ENABLED` | 硬件在环仿真模式（电机锁死） |
| 16 | `MAV_MODE_FLAG_STABILIZE_ENABLED` | 电子增稳已开启 |
| 8 | `MAV_MODE_FLAG_GUIDED_ENABLED` | 引导模式，按航点/指令飞行 |
| 4 | `MAV_MODE_FLAG_AUTO_ENABLED` | 全自主模式，飞控自己找目标 |
| 2 | `MAV_MODE_FLAG_TEST_ENABLED` | 测试模式（仅开发用） |
| 1 | `MAV_MODE_FLAG_CUSTOM_MODE_ENABLED` | 自定义模式标志 |

**常见组合**：

```
209 = 128+64+16+1  → 已解锁 + 遥控 + 增稳 + 自定义 → custom_mode 字段有效
 81 =      64+16+1  → 未解锁 + 遥控 + 增稳 + 自定义
192 = 128+64       → 已解锁 + 纯手动（无增稳）
```

Python 提取单个位：

```python
armed   = bool(msg.base_mode & 128)
guided  = bool(msg.base_mode & 8)
auto    = bool(msg.base_mode & 4)
stabilize = bool(msg.base_mode & 16)
```

### A.2 `onboard_control_sensors_*`（SYS_STATUS）— MAV_SYS_STATUS_SENSOR

> 三个字段用同一个位掩码：`_present`（存在）、`_enabled`（启用）、`_health`（健康）。
> 健康字段：**1 = 正常，0 = 故障**。

| 位值 | 标识符 | 传感器 |
|:----:|--------|--------|
| **1** | `MAV_SYS_STATUS_SENSOR_3D_GYRO` | 3D 陀螺仪 |
| 2 | `MAV_SYS_STATUS_SENSOR_3D_ACCEL` | 3D 加速度计 |
| 4 | `MAV_SYS_STATUS_SENSOR_3D_MAG` | 3D 磁力计（罗盘） |
| 8 | `MAV_SYS_STATUS_SENSOR_ABSOLUTE_PRESSURE` | 绝压传感器（气压计） |
| 16 | `MAV_SYS_STATUS_SENSOR_DIFFERENTIAL_PRESSURE` | 差压传感器（空速计） |
| **32** | `MAV_SYS_STATUS_SENSOR_GPS` | GPS |
| 64 | `MAV_SYS_STATUS_SENSOR_OPTICAL_FLOW` | 光流传感器 |
| 128 | `MAV_SYS_STATUS_SENSOR_VISION_POSITION` | 视觉定位（ArUco 等） |
| 256 | `MAV_SYS_STATUS_SENSOR_LASER_POSITION` | 激光定位 |
| 512 | `MAV_SYS_STATUS_SENSOR_EXTERNAL_GROUND_TRUTH` | 外部地面真值（Vicon/Leica） |
| 1024 | `MAV_SYS_STATUS_SENSOR_ANGULAR_RATE_CONTROL` | 角速度控制 |
| 2048 | `MAV_SYS_STATUS_SENSOR_ATTITUDE_STABILIZATION` | 姿态增稳 |
| 4096 | `MAV_SYS_STATUS_SENSOR_YAW_POSITION` | 偏航位置控制 |
| 8192 | `MAV_SYS_STATUS_SENSOR_Z_ALTITUDE_CONTROL` | Z 轴/高度控制 |
| 16384 | `MAV_SYS_STATUS_SENSOR_XY_POSITION_CONTROL` | XY 位置控制 |
| 32768 | `MAV_SYS_STATUS_SENSOR_MOTOR_OUTPUTS` | 电机输出 |
| 65536 | `MAV_SYS_STATUS_SENSOR_RC_RECEIVER` | RC 接收机 |
| 1048576 | `MAV_SYS_STATUS_GEOFENCE` | 电子围栏 |
| 2097152 | `MAV_SYS_STATUS_AHRS` | AHRS 姿态估计子系统 |
| 4194304 | `MAV_SYS_STATUS_TERRAIN` | 地形子系统 |
| 16777216 | `MAV_SYS_STATUS_LOGGING` | 日志记录 |
| 33554432 | `MAV_SYS_STATUS_SENSOR_BATTERY` | 电池 |
| 67108864 | `MAV_SYS_STATUS_SENSOR_PROXIMITY` | 避障/接近传感器 |
| 134217728 | `MAV_SYS_STATUS_SENSOR_SATCOM` | 卫星通信 |
| 268435456 | `MAV_SYS_STATUS_PREARM_CHECK` | 预解锁检查（解锁后恒为健康） |
| 536870912 | `MAV_SYS_STATUS_OBSTACLE_AVOIDANCE` | 避障/防撞 |
| 1073741824 | `MAV_SYS_STATUS_SENSOR_PROPULSION` | 推进系统（电调/电机/桨） |
| 2147483648 | `MAV_SYS_STATUS_EXTENSION_USED` | 扩展位域已启用 |

**最常用的几个**：

```python
health = msg.onboard_control_sensors_health

gps_ok    = bool(health & 32)       # GPS 健康
gyro_ok   = bool(health & 1)        # 陀螺仪健康
accel_ok  = bool(health & 2)        # 加速度计健康
mag_ok    = bool(health & 4)        # 罗盘健康
baro_ok   = bool(health & 8)        # 气压计健康
battery_ok = bool(health & 33554432) # 电池健康
```

> **注意**：以上是 SYS_STATUS **主字段**（32位）的位掩码。另外还有三个 `_extended` 字段，
> 目前只定义了 2 个扩展位：bit0=回收系统（降落伞）、bit1=泄漏检测。基本用不到。
