# Mission 航点参数参考

> 用途：写 `MISSION_ITEM_INT` 时，每个 MAV_CMD 的 `param1~7` 到底填什么。
> 配套：`消息字段参考.md` 的 "Mission 协议" 章节。
> 来源：common.xml（pymavlink 2.4.49 实测）。

---

## 一、先搞清楚字段和 param 的对应关系

`MISSION_ITEM_INT` 有 7 个"参数"，但字段只有 param1~4 + x/y/z：

```
MAVLink 逻辑参数     MISSION_ITEM_INT 字段
─────────────────────────────────────────
param1              → param1  (float)
param2              → param2  (float)
param3              → param3  (float)
param4              → param4  (float)
param5              → x       (int32)
param6              → y       (int32)
param7              → z       (int32)
```

**导航类指令（NAV_*）的坐标总是 param5=纬度 / param6=经度 / param7=高度**，所以填在 `x/y/z` 字段里。

## 二、坐标单位（frame 决定）

| frame | x | y | z |
|-------|---|---|---|
| `GLOBAL_RELATIVE_ALT`(3) 推荐 | 纬度 ×1e7 | 经度 ×1e7 | **相对起飞点高度** mm |
| `GLOBAL`(0) | 纬度 ×1e7 | 经度 ×1e7 | 绝对海拔 MSL mm |

例：纬度 39.1234567 → `x = int(39.1234567 * 1e7) = 391234567`；高度 10 米 → `z = 10000`（mm）。

## 三、投递场景 MAV_CMD 参数详解

### NAV_WAYPOINT（16）— 飞往航点

| param | 填什么 |
|-------|--------|
| 1 | 悬停时间（秒，到达后停多久）。多旋翼有效 |
| 2 | 到达判定半径（米，进入这个半径就算到） |
| 3 | 0=穿过航点；>0=绕过半径（正=顺时针，负=逆时针）。**一般填 0** |
| 4 | 到达时机头朝向（度）。**填 `float('nan')` = 用系统默认**（别填 0，否则机头朝北） |
| 5 (x) | 纬度 ×1e7 |
| 6 (y) | 经度 ×1e7 |
| 7 (z) | 高度（mm，看 frame） |

### NAV_TAKEOFF（22）— 起飞

| param | 填什么 |
|-------|--------|
| 1 | 最小俯仰角（无空速计可忽略，填 0 或默认） |
| 4 | 起飞后机头朝向，填 `float('nan')` 用默认 |
| 5 (x) | 起飞点纬度 ×1e7（可填 home） |
| 6 (y) | 起飞点经度 ×1e7 |
| 7 (z) | **起飞目标高度**（相对起飞点，mm） |

### NAV_LAND（21）— 降落

| param | 填什么 |
|-------|--------|
| 1 | 中止降落的最小高度（0=系统默认） |
| 2 | 精确降落模式（0=关） |
| 4 | 偏航角，`float('nan')` |
| 5 (x) / 6 (y) | 降落点经纬度 |
| 7 (z) | 降落点地面高度（当前 frame 下，相对高度时填 0） |

### NAV_RETURN_TO_LAUNCH（20）— 返航

**param1~7 全部留空**。返航点（home）飞控自己记录，不需要坐标。

### NAV_LOITER_TIME（19）— 悬停 N 秒

| param | 填什么 |
|-------|--------|
| 1 | **悬停秒数** |
| 3 | 悬停半径（正=顺时针，负=逆时针），多旋翼一般填 0 |
| 4 | 偏航角，`float('nan')` |
| 5/6/7 (x/y/z) | 悬停点坐标 |

### NAV_LOITER_UNLIM（17）— 无限悬停（直到下一条指令）

| param | 填什么 |
|-------|--------|
| 3 | 悬停半径 |
| 4 | 偏航角 |
| 5/6/7 (x/y/z) | 悬停点坐标 |

### DO_SET_SERVO（183）— 控制舵机（开舱投放用）

| param | 填什么 |
|-------|--------|
| 1 | **舵机编号**（servo 通道号） |
| 2 | **PWM 值**（1000~2000 μs，决定舵机角度/舱门开合） |
| 3~7 | 空（填 0） |

### DO_GRIPPER（211）— 机械爪投放

| param | 填什么 |
|-------|--------|
| 1 | 机械爪编号 |
| 2 | 动作：**1=抓取(GRAB)，0=释放(RELEASE)** |
| 3~7 | 空 |

### DO_CHANGE_SPEED（178）— 改变飞行速度（投放前减速）

| param | 填什么 |
|-------|--------|
| 1 | 速度类型：0=空速，**1=地速**（多旋翼用 1） |
| 2 | **目标速度（m/s）**。-1=不变，-2=恢复默认 |
| 3 | 油门（-1=不变） |
| 4 | 0=绝对，1=相对 |
| 5~7 | 空 |

## 四、命令型指令（command_long 用，不是 mission item）

### MISSION_START（300）— 启动任务

| param | 填什么 |
|-------|--------|
| 1 | 起始 item 序号（默认 0） |
| 2 | 结束 item 序号（默认最后一个） |

### COMPONENT_ARM_DISARM（400）— 解锁/上锁

| param | 填什么 |
|-------|--------|
| 1 | **1=解锁，0=上锁** |
| 2 | 0=正常（有安全检查），21196=强制 |

## 五、完整投递 mission 示例

一条投递路线（frame 全部用 `GLOBAL_RELATIVE_ALT`=3，autocontinue=1）：

| seq | command | 关键参数 |
|:---:|---------|---------|
| 0 | `NAV_TAKEOFF`(22) | z=10m 起飞高度 |
| 1 | `NAV_WAYPOINT`(16) | x/y=投放点坐标，z=投放高度，param2=到达半径1m，param4=NaN |
| 2 | `DO_CHANGE_SPEED`(178) | param1=1(地速)，param2=1.5（减速到 1.5m/s） |
| 3 | `DO_SET_SERVO`(183) | param1=舵机号，param2=开舱 PWM |
| 4 | `NAV_LOITER_TIME`(19) | param1=3（投放后悬停 3s），x/y/z=投放点 |
| 5 | `NAV_RETURN_TO_LAUNCH`(20) | 全空 |
| 6 | `NAV_LAND`(21) | x/y=home，z=0 |

> 投放动作（seq 3 的 DO_SET_SERVO）飞控会在飞到 seq 1 的航点后自动执行，不需要服务器实时发"开舱"。

## 六、两个必踩的坑

1. **param4（yaw）别填 0**：0 表示"机头朝北"，不是"保持默认"。要"用系统默认航向"必须填 `float('nan')`。

2. **坐标单位别搞错**：经纬度是 **度×1e7**（整数），高度是 **毫米**（整数）。`x/y/z` 是 int32，别填成浮点度数。
