## 依赖方向（单向，无循环）

```
config.py / logger.py          ← 最底层，谁都能 import，它不 import 别人
    ↑
mavlink/  command/             ← 能力层，依赖 config/logger
    ↑
core/drone.py                  ← 聚合根，依赖 mavlink + command + config/logger
    ↑
web/业务层  安全层（待写）      ← 依赖 core
```

**铁律**：下层（mavlink/command）**不 import** 上层（core），要用 drone 靠参数传进来（duck-typing）。

## 关键决策

| 决策 | 结论 |
|------|------|
| 定义表 | JSON 驱动：`commands.json → load_specs → CommandSpec`，加命令 = 加 JSON 一行 |
| 转译 | `_bind` 生成**完整命令函数**（`self.takeoff(10)` 自带构造+台账+追踪），不是薄转发 execute |
| 台账存什么 | 只存 `name/cmd/params` + 执行状态，**不存 msg 对象**（重发时 `_encode` 重建） |
| 台账分层 | 定义(spec) / 台账(record) / 引擎(manager) 三文件，定义字段只在 spec 一份 |
| 内存 vs 磁盘 | 内存 `runs` 存所有指令(每条带状态,50 条有界)；JSON 终态追加**全量** |
| 落盘结构 | 按飞机+日期：一次进程一个文件夹，文件夹里每个 sys_id 一个 `.jsonl` |
| 并发 | 单飞 + 单锁（COMMAND_ACK 无序列号）；业务层阻塞、控制层非阻塞 |
| 目录 | core/command/mavlink 分层，config/logger 归位到根目录 |
