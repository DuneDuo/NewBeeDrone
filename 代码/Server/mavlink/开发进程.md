## 接口现状

```python
from mavlink import Drone, register, dispatch

Drone.registry                          # dict[int, Drone]
drone = Drone.registry[1]
#id
drone.sys_id
# 飞行状态
drone.armed / flight_mode / sys_status
drone.lat / lon / alt_rel / alt_ter
drone.roll / pitch / yaw / hdg
drone.vx / vy / vz / time_boot

# 传感器
drone.sensor.gps / gyro / accel / mag / baro / motor / rc / battery
drone.sensor.check()   # → {name: None|False|True}

# 指令
drone.send_command_long(cmd_id, param1=...)
drone.param_request_read(b"PARAM")
drone.param_set(b"PARAM", value)

# 连接状态
drone.running          # 是否在线
drone.disconnected_at  # 当前断开时间（在线时为 None）

# 任务
drone.current_waypoint
drone.pending_commands  # 待确认指令（声明但未启用）
```

## 关键决策

| 决策 | 结论 |
|------|------|
| 传感器存储 | `Sensor` 独立类，属性方式（不用位掩码） |
| 断线重连 | 方案 A（批量拷贝 `__dict__`），`close()` 不删 registry |
| 断连记录 | 只保留 `disconnected_at`，历史查日志 |
| commands 层 | 函数风格，不搞字典 |
