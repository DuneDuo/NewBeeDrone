# PX4 飞控参数配置

> 一块**出厂** PX4 飞控 → 适配本系统（树莓派串口 + 4G 链路 + 换电），需要改的参数。
> 最后更新：2026-08-25

---

## 1. 串口 + MAVLink 数据流

让树莓派能通过 TELEM1 串口收到 MAVLink 数据。

| 参数 | 值 | 说明 |
|------|------|------|
| `MAV_0_CONFIG` | TELEM1 | MAVLink 流 0 走 TELEM1 串口 |
| `SER_TEL1_BAUD` | 57600 | TELEM1 波特率，匹配树莓派 ttyAMA0 |
| `MAV_0_FLOW_CTRL` | 0 (Off) | 无流控 |
| `MAV_0_RADIO_CTL` | 0 (Off) | **关键**：飞控主动发 MAVLink，不等 GCS 握手。开着的话飞控会等收到 GCS 数据才开始发 |

## 2. 4G 数据链 failsafe

4G 断连时飞控**自己**触发保护动作，不依赖服务器发指令。

| 参数 | 值 | 说明 |
|------|------|------|
| `COM_DL_LOSS_T` | 5 | 数据链丢失判定超时（秒）。别配 1s——4G 切基站就 1~2s，太短会频繁误触发 |
| `NAV_DLL_ACT` | 2 (RTL) | 数据链丢失 → 返航 |

## 3. RC 输入

飞控端没接真实 RC 接收机（遥控走 4G 粗指令），需要禁用 RC 输入。

| 参数 | 值 | 说明 |
|------|------|------|
| `COM_RC_IN_MODE` | 3 (Disabled) | 禁用 RC 输入，纯 MAVLink/GCS 控制。不配的话飞控会因"RC 丢失"误触发 failsafe 或拒绝解锁 |

## 4. 电池（21700 锂离子）

21700 是 Li-Ion（锂离子），不是 LiPo。飞控默认按 LiPo 曲线估剩余%，会不准。

| 参数 | 值 | 说明 |
|------|------|------|
| 电池类型/满空电压 | 按 Li-Ion 配 | 参数名待查：`BAT1_*` 系列，可能是 `BAT1_V_CHARGED`/`BAT1_V_EMPTY`（满 4.2V / 空 3.0V），或专用类型参数 |

---

## 关键枚举

**`NAV_DLL_ACT`（数据链丢失动作）**：

| 值 | 动作 |
|:--:|------|
| 0 | Disabled |
| 1 | Hold（悬停） |
| **2** | **Return（返航 RTL）** ← 推荐 |
| 3 | Land（降落） |
| 4 | Auto（继续任务） |
| 5 | Terminate（终止） |

**`COM_RC_IN_MODE`（RC 输入模式）**：

| 值 | 含义 |
|:--:|------|
| 0 | RC + Joystick（默认） |
| 1 | 仅 RC |
| 2 | 仅 Joystick |
| **3** | **Disabled（禁用）** ← 没遥控器用这个 |

---

## 改完记得

- 重新上锁/解锁（或重启飞控）才生效
- **failsafe 必须实测**：地面断 4G，验证飞机会不会自动 RTL
- 服务器要持续发心跳（`drone.py` 的 `heartbeat_loop`），否则飞控误判数据链丢失、自己 RTL
- 电池参数名待 QGC 查 `BAT1_*` 确认后回填
